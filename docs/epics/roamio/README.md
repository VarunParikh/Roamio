# Epic: Roamio Phase 1 (Android pilot)

One epic, one feature set. It mirrors the Zest project's layout: `docs/core/` holds product-wide documents, and `docs/epics/` holds the work.

| Stage | Folder | Documents |
|---|---|---|
| Discovery | `discovery/` | [Assumptions and risk register](discovery/assumptions-and-risk-register.md). No market research or personas exist, because none was done. |
| Requirements | `requirements/` | [BRD](requirements/business-requirements.md), [Product spec (PRD)](requirements/product-spec.md), [User stories and traceability](requirements/user-stories.md) |
| Design | `design/` | [Architecture](design/architecture.md), [Data model](design/data-model.md), [ADRs](design/adr/README.md) |
| Build and verify | `verify/` | [Test plan](verify/test-plan.md), [security review](verify/reviews/security-2026-10.md), [code review](verify/reviews/code-review-2026-10.md) |
| Release | `release/` | [Release checklist](release/release-checklist.md), [Known limitations](release/known-limitations.md), [Pilot guide](release/pilot-guide.md), [Privacy notice](release/privacy-notice.md), [Breach response](release/breach-response.md) |

**Kept outside this folder, because code, CI or the nightly routine point to them:**
- `tasks/`: [plan](../../../tasks/plan.md), [task list](../../../tasks/todo.md), [handover](../../../tasks/HANDOVER.md), [screen states](../../../tasks/screen_states.md)
- `design/`: [DESIGN.md](../../../design/DESIGN.md) and reference screens
- `docs/`: [SETUP](../../SETUP.md), [RELEASING](../../RELEASING.md), [REMOTE_CONFIG](../../REMOTE_CONFIG.md)

Approval status of every document: [approval register](../../core/approval-register.md). Disagreements between documents: [conflicts log](../../core/open-conflicts.md).
