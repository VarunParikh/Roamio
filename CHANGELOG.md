# Changelog

Release notes shown in the app's update popup. Newest first; one `## X.Y.Z`
section per release (see [docs/RELEASING.md](docs/RELEASING.md)).

## 1.0.1

- Updating is more reliable: Download update now opens the release page. Tap the .apk file under Assets, then open it to install.

If this update's download gets stuck, open github.com/VarunParikh/Roamio/releases/latest and tap the .apk file there.

## 1.0.0

- A new app icon.
- Mark a payment as settled in any currency, and see what it comes to in yours.
- The same payment marked twice now counts once.
- Tabs show a place's name, or its coordinates when there's no name.
- Scan bill finds the page and only fills in a total it can trust. Please check it before saving.

## 0.1.0

- First pilot release of Roamio.
- Plan adventures with your squad, add tabs and split them fairly, in any currency.
- Works offline; changes sync when you are back online.
