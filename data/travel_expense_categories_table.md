# Travel Expense Categories

| Category | Typical Line Items | Payment Timing |
| :--- | :--- | :--- |
| **Pre-Trip Preparation** | Visas, passport renewals, travel insurance, vaccinations, medication, specialized luggage, travel gear | Pre-departure |
| **Primary Transportation** | Round-trip flights, long-distance trains, intercity buses, ferry tickets, baggage fees, seat selection | Pre-departure |
| **Accommodation** | Hotel rooms, hostels, vacation rental stays, resort fees, city tourism taxes, security deposits | Pre-trip / On-arrival |
| **Local Transportation** | Metro/subway passes, local bus tickets, ride-hailing (Uber/Grab), taxis, car/scooter rentals, fuel, tolls, parking | Daily during trip |
| **Food & Dining** | Breakfast, lunch, dinner, street food, cafes, coffee, groceries, bottled water, snacks, culinary experiences | Daily during trip |
| **Activities & Sightseeing** | Museum tickets, historic monument passes, guided city tours, national park entries, adventure excursions, event tickets | Mixed (Pre-booked / On-site) |
| **Shopping & Souvenirs** | Local crafts, textiles, duty-free items, regional gifts, postcards, apparel purchases | Throughout trip / Departure |
| **Connectivity & Technology** | Local SIM cards, eSIM data plans, portable Wi-Fi rentals, power adapters, replacement cables | Pre-trip / On-arrival |
| **Incidentals** | Currency exchange margins, ATM withdrawal fees, service tips/gratuities, laundromat/laundry services, luggage storage | As incurred |
| **Miscellaneous** | Unplanned pharmacy runs, replacement toiletries, umbrellas/ponchos, printouts, unexpected baggage surcharges, emergency contingency buffer | As incurred / Emergency |
